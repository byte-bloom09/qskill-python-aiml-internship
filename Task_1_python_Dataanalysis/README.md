# Task 1 – Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix dataset using Python.

The objective of this task was to clean the dataset, analyze patterns, and extract meaningful insights about content distribution, genres, countries, and trends over time.

---

## 🎯 Objectives

- Understand the structure of the Netflix dataset
- Perform data cleaning and preprocessing
- Analyze content distribution (Movies vs TV Shows)
- Identify top genres
- Analyze country-wise content production
- Study trends in content release over the years
- Visualize insights using graphs

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🧹 Data Cleaning Steps

- Handled missing values
- Converted date columns to datetime format
- Split multiple genres into individual entries
- Standardized categorical values
- Removed unnecessary columns (if applicable)

---

## 📊 Key Insights

- Movies are more common than TV Shows on Netflix.
- Certain genres dominate the platform.
- The United States contributes the highest number of titles.
- There has been a significant increase in content after 2015.
- Genre distribution varies by region.
